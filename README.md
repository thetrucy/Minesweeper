# Minesweeper
This is an implemetation of a classic Minesweeper. This game is built using C++ and raylib graphics library.
## References
During the development of this project, I used the following resources for guidance:
* Raylib Official Documentation: The primary reference for using Raylib's functions. [Raylib](https://www.raylib.com/)
* Minesweeper Game Logic: For understanding the game mechanics and logic, I referred to:
  Minesweeper Algorithm Guide by GeeksforGeeks.
* C++ and Raylib Tutorials:
  Raylib C++ tutorials for integrating the library with C++. [Link](https://www.youtube.com/watch?v=RGzj-PF7D74)
## Future Improvements
* UX/UI design: I personally feel that this project is not user-friendly as it doesn't have any guidance. Instructions will be added in later models.
* Difficulty Levels: Varying difficulty by adding mines and changing grid size.
* Timer and Scoreboard: Implement a timer and a high-score system to track the best times.
